Политика конфиденциальности AdminKIT WebLogin

Дата последнего обновления: 2 октября 2026 г.

1. Назначение

AdminKIT WebLogin — корпоративное расширение Google Chrome, используемое совместно с системой администрирования AdminKIT.

Единственная функция расширения — выполнение запрошенной авторизованным оператором AdminKIT авторизации в поддерживаемом веб-сервисе внутри Chrome-сессии выбранного Windows-пользователя и возврат результата этой операции локальному AdminKIT runtime.

В текущей версии поддерживаются Mail.ru и корпоративные порталы Bitrix24 по HTTPS.

2. Какие данные обрабатываются

Для выполнения функции WebLogin расширение может обрабатывать:

  • адрес электронной почты или логин аккаунта;
  • пароль, необходимый для выполнения конкретной операции авторизации;
  • состояние авторизации;
  • URL страниц, участвующих в текущем процессе входа;
  • данные формы авторизации;
  • ограниченное содержимое веб-страницы, необходимое для обнаружения элементов формы и определения результата входа;
  • идентификатор и email текущего пользователя Bitrix24, когда это необходимо для проверки активного аккаунта.

Расширение не предназначено для обработки финансовых, медицинских или геолокационных данных.

Расширение не читает содержимое электронной почты или личных сообщений в рамках своей заявленной функции.

3. Использование учётных данных

Учётные данные используются исключительно для выполнения операции авторизации, явно запрошенной через AdminKIT.

Пароль передаётся только соответствующему сервису авторизации, выбранному оператором AdminKIT.

Расширение не сохраняет пароль в Chrome Storage. Пароль не записывается расширением в журналы и не включается в результаты выполнения операции.

Локальный AdminKIT runtime использует краткоживущий одноразовый механизм передачи секрета. Пароль не сохраняется в обычной базе заданий AdminKIT, audit-записях, job results или command line.

4. Native Messaging

Расширение использует Chrome Native Messaging для локального взаимодействия с установленным на том же Windows-компьютере компонентом AdminKIT WebLogin.

Native Messaging используется для получения команды WebLogin и возврата результата операции.

Он не используется для передачи пользовательских данных рекламным сетям, аналитическим сервисам или брокерам данных.

5. Доступ к веб-сайтам

Для Mail.ru расширение использует страницы Mail.ru и VK ID, участвующие в процессе авторизации.

Для Bitrix24 поддерживаются корпоративные HTTPS-порталы с различными доменными именами.

AdminKIT проверяет запрошенный сервис и адрес до выполнения операции. Доступ к страницам используется только во время активной операции WebLogin и не предназначен для общего наблюдения за историей просмотра.

6. CAPTCHA и многофакторная аутентификация

AdminKIT WebLogin не обходит CAPTCHA и многофакторную аутентификацию. Если сервис требует CAPTCHA или второй фактор, автоматизированная операция останавливается и AdminKIT сообщает о необходимости действия пользователя.

7. Передача данных третьим сторонам

Данные авторизации передаются соответствующему веб-сервису только в объёме, необходимом для выполнения запрошенного входа.

Пользовательские данные не продаются и не передаются рекламным сетям, брокерам данных или сторонним аналитическим сервисам.

8. Хранение данных

Расширение не ведёт собственную постоянную базу паролей или учётных данных.

Краткоживущие секреты AdminKIT являются одноразовыми и удаляются после получения или истечения срока действия.

Для администрирования и диагностики могут сохраняться нечувствительные технические данные, такие как версия runtime, версия расширения, версия протокола и итоговый технический статус операции.

9. Реклама и профилирование

AdminKIT WebLogin не:

  • продаёт пользовательские данные;
  • использует данные для рекламы;
  • использует данные для поведенческого профилирования;
  • передаёт данные брокерам данных;
  • использует данные для определения кредитоспособности;
  • использует данные для целей, не связанных с заявленной функцией авторизации.

10. Ограниченное использование данных

Использование пользовательских данных ограничено предоставлением и обеспечением основной функции AdminKIT WebLogin.

Использование информации, полученной через API Chrome, соответствует требованиям Chrome Web Store User Data Policy, включая Limited Use.
